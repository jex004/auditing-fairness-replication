Code to Recreate "Auditing Fairness by Betting" paper replication

# Content
-`adult_income_eda.ipynb`: Contains EDA conducted on the dataset used to train the binary classifier, as well as figures used in the Data Description within the report's introduction

-`clean_df.ipynb`: A cleaned version of the UCI Income dataset

-`data.ipynb`: Used to load the dataset

-`etl.py`: The code used to drop columns, clean entries, and remove null values

-`final_df`: A final version of the UCI Income dataset to be used in model training

-`methods.py`: The code used to run the sequential hypothesis test once a model has been developed
